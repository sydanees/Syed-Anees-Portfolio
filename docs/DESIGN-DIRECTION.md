# Design Direction

## Desired feeling

Quietly confident. Minimal but not sterile. Editorial but usable. Slightly offbeat without becoming gimmicky.

The site should communicate craft and maturity through restraint.

## Visual principles

### Typography
Typography should do a large part of the visual work. Favor a distinctive, highly legible type system with clear contrast between display and body text.

Avoid using typography as decoration alone.

### Layout
Use a strong grid but allow intentional asymmetry.

Use:
- Large negative space
- Unexpected alignment
- Changes in scale
- Editorial composition
- Clear visual rhythm

Avoid:
- Repeating identical cards
- Everything centered
- Every section looking like a component library

### Colour
Start restrained. Let project imagery and a small number of intentional accents create variety.

Do not default to gradients.

### Imagery
Prefer real project imagery, screenshots, photography and artifacts from actual work.

Do not fabricate project visuals that imply real product outcomes.

## Hero direction

The hero should establish:
- who I am
- what I do
- personality
- the "expensive problems disappear" idea

A visual metaphor for simplifying/removing complexity is encouraged, but the interaction should be meaningful rather than cinematic for its own sake.

## Selected work

Projects should feel like editorial stories rather than a card catalog.

Every project needs:
- title
- company/product
- role
- year
- concise problem/context
- outcome where available
- strong visual

Hover/scroll behavior should help users explore rather than merely decorate.

## About

Human and direct. Avoid a resume dump.

Use:
- bio
- skills
- tools/stack
- recognitions
- brands/products
- photography

## Case studies

Preferred story:
Context → Problem → Insight → Decision → Design → Iteration → Outcome → Reflection

Do not force a fake UX process onto a project.

Include a TL;DR video near the beginning when available.

Use sticky section navigation for long case studies.

## Motion principles

Motion should be:
- fast enough to preserve flow
- subtle where it supports hierarchy
- expressive where it establishes personality
- reduced/simplified on mobile where needed
- disabled or reduced when the user prefers reduced motion

One memorable interaction should become a recognizable signature.

## Anti-AI-slop test

Before approving a major visual decision, ask:

Would this look intentional if nobody knew AI was involved?

Would this blend into a collection of 100 AI-generated designer portfolios?

If yes, improve the underlying composition, typography, specificity or storytelling. Do not simply make it stranger.
